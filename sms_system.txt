I want it so that parents can fund the children wallet by paybill and account number where by the account number is the childs dishi Id , for the aprents without phone , i also want to make it so that it can be done via sms , show me how to do this.
To accommodate parents with feature phones (non-smartphones), you need to shift from relying solely on STK Push (M-PESA Express) to implementing M-PESA C2B (Customer to Business) for Paybill payments, paired with a two-way SMS gateway (like Africa's Talking).

Here is exactly how to architect and implement this extension into your current Python backend and Firebase setup.

1. M-PESA Paybill (C2B) Architecture
When a parent uses the standard M-PESA SIM tool/App to pay via your Paybill Number and enters the Child’s DISHI ID as the Account Number, Safaricom sends a webhook (callback) to your backend.

The C2B Workflow
1
Register C2B URLs with Safaricom
Configure your Python backend to register a ValidationURL and a ConfirmationURL via the Daraja C2B API. Safaricom will send transaction alerts to these endpoints.

2
Process the Confirmation Callback
Safaricom hits your ConfirmationURL with a JSON payload containing the amount, payer's phone number, and the BillRefNumber (which is the entered DISHI ID).

3
Validate and Credit the Student Wallet
The backend extracts the DISHI ID, searches Firestore for the matching student document, credits their wallet balance, and records the ledger transaction.

4
Trigger SMS Confirmation
If the transaction is successful, the backend uses an SMS gateway to text the parent a receipt, confirming their child's wallet has been funded.


Python Backend Code (Vercel/Flask)
Here is how your backend should parse the Safaricom C2B confirmation payload and update Firestore:

Python
from flask import Flask, request, jsonify
import firebase_admin
from firebase_admin import credentials, firestore
import requests

app = Flask(__name__)

# Initialize Firebase Admin
cred = credentials.Certificate("path/to/serviceAccountKey.json")
firebase_admin.initialize_app(cred)
db = firestore.client()

SMS_GATEWAY_URL = "https://api.africastalking.com/version1/messaging"
SMS_USERNAME = "your_username"
SMS_API_KEY = "your_api_key"

def send_sms(to_phone, message):
    """Helper to notify parents without the app via SMS"""
    headers = {
        "ApiKey": SMS_API_KEY,
        "Accept": "application/json",
        "Content-Type": "application/x-www-form-urlencoded"
    }
    data = {
        "username": SMS_USERNAME,
        "to": to_phone,
        "message": message
    }
    requests.post(SMS_GATEWAY_URL, data=data, headers=headers)

@app.route('/api/v1/mpesa/c2b-confirmation', methods=['POST'])
def mpesa_c2b_confirmation():
    mpesa_data = request.get_json()
    
    # Extract values from Safaricom C2B Payload
    transaction_id = mpesa_data.get("TransID")
    amount = float(mpesa_data.get("TransAmount"))
    dishi_id = mpesa_data.get("BillRefNumber").strip().upper() # Account Number entered by parent
    parent_phone = f"+{mpesa_data.get('MSISDN')}" # Payer phone number
    
    # 1. Locate student by DISHI ID in Firestore
    students_ref = db.collection('students').where('dishi_id', '==', dishi_id).limit(1).get()
    
    if not students_ref:
        # If student doesn't exist, log to a suspense account for manual reversal
        db.collection('suspense_transactions').document(transaction_id).set(mpesa_data)
        send_sms(parent_phone, f"DISHI: Transaction failed. Student ID {dishi_id} not found. Contact support.")
        return jsonify({"ResultCode": 0, "ResultDesc": "Accepted (Sent to Suspense)"})

    student_doc = students_ref[0]
    student_data = student_doc.to_dict()
    student_ref = db.collection('students').document(student_doc.id)
    
    # 2. Update wallet balance atomically (less top-up fee)
    net_amount = amount - 1.0 # Your Ksh 1 Top-up fee
    
    @firestore.transactional
    def update_wallet(transaction, ref):
        snapshot = ref.get(transaction=transaction)
        current_balance = snapshot.get('wallet_balance') or 0.0
        new_balance = current_balance + net_amount
        transaction.update(ref, {'wallet_balance': new_balance})
        return new_balance

    transaction = db.transaction()
    new_bal = update_wallet(transaction, student_ref)
    
    # 3. Record transaction ledger entry
    db.collection('transactions').document(transaction_id).set({
        "type": "top_up",
        "method": "c2b_paybill",
        "amount": amount,
        "fee": 1.0,
        "net_amount": net_amount,
        "student_id": student_doc.id,
        "dishi_id": dishi_id,
        "parent_phone": parent_phone,
        "timestamp": firestore.SERVER_TIMESTAMP
    })
    
    # 4. Notify parent via SMS
    sms_msg = f"Confirmed. Ksh {net_amount} credited to DISHI ID: {dishi_id}. New student balance is Ksh {new_bal}."
    send_sms(parent_phone, sms_msg)
    
    return jsonify({"ResultCode": 0, "ResultDesc": "Success"})
2. Interactive SMS Functionality (Two-Way SMS)
To give parents without smartphones the ability to check their child's balance or manage configurations without an app, you can lease a Short Code or Incoming Keyword from an SMS provider.

Whenever a parent sends an SMS to your shortcode, the provider routes it via a POST webhook to your Python backend.

SMS Request Handling Logic
Create a dedicated incoming SMS endpoint (/api/v1/sms/incoming) to process commands like:

BAL [DISHI_ID] (e.g., BAL D5521) — Returns the student's current wallet balance.

Python
@app.route('/api/v1/sms/incoming', methods=['POST'])
def handle_incoming_sms():
    # Parsing fields sent by Africa's Talking incoming SMS webhook
    sender = request.form.get("from") # Parent's phone number
    text = request.form.get("text", "").strip().upper() 
    
    parts = text.split()
    if not parts:
        return jsonify({"status": "ignored"})
        
    command = parts[0]
    
    if command == "BAL" and len(parts) > 1:
        target_dishi_id = parts[1]
        
        # Query student
        students = db.collection('students').where('dishi_id', '==', target_dishi_id).limit(1).get()
        if students:
            student_data = students[0].to_dict()
            bal = student_data.get('wallet_balance', 0.0)
            response_msg = f"DISHI: The current wallet balance for ID {target_dishi_id} is Ksh {bal}."
        else:
            response_msg = f"DISHI: Student ID {target_dishi_id} was not found in our system."
            
        send_sms(sender, response_msg)
        
    return jsonify({"status": "processed"}), 200
3. Real-Time Transaction Alerts (Offline Push)
In your original design, you planned to use Firebase Cloud Messaging (FCM) to send a notification to the parent when a student spends money. For parents without a smartphone, your system must dynamically switch to an SMS channel.

Modify your spending webhook or Cloud Function to check if the parent has an active app token:

Python
def notify_parent_on_spend(parent_uid, parent_phone, student_name, amount_spent):
    # Check if parent has an active FCM registration token
    parent_user = db.collection('users').document(parent_uid).get()
    fcm_token = parent_user.to_dict().get('fcm_token') if parent_user.exists else None
    
    msg_body = f"Alert: {student_name} spent Ksh {amount_spent} at the school kitchen."
    
    if fcm_token:
        # Send smartphone push notification via FCM
        trigger_fcm_push(fcm_token, "DISHI Wallet Alert", msg_body)
    else:
        # Fallback to SMS if they don't use the app
        send_sms(parent_phone, f"DISHI: {msg_body}")
